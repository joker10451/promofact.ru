# ПромоФакт — сохрани характер, улучши UX

## Почему отклонили Editorial 3.0
По пользовательской оценке опубликованный дизайн смотрится выразительнее. На одинаковых ширинах исходная сборка `main` и Editorial 3.0 показали: Unbounded, высококонтрастный темно-синий, коралловый CTA и компактные узнаваемые логотипы дают сайту характер. Полная смена палитры/типографики на бежевую Georgia делает купонный сервис похожим на журнальный шаблон.

## Новый принцип
**Никакого "редизайна ради редизайна".** Эксперимент `design/promo-3-1-polish-current` создан **не от PR #82**, а от `main`, чтобы не вносить отказавшийся от узнаваемости Editorial 3.0.

**Сохранить:** фирменный логотип, темно-синий `#0b102b`, яркий коралловый `#ff3355`, Unbounded/Golos, каталожную структуру, боковые фильтры, реальную механику купонов, указание источника/ERID, рекламные кампании на своих страницах.

**Изменить узко и проверяемо:**
- Сжать мобильный и десктопный первый экран: убрать лишнюю вертикальную пустоту и четыре декоративные метки доверия; оставить реальную статистику и бесплатность.
- Сохранить узнаваемый заголовок «Найдите скидку. Заплатите меньше.» и важный поисковый текст.
- Сохранить существующий поиск/автодополнение/аналитику, сделать placeholder короче для телефона.
- Предлагать в Hero **только существующие активные магазины** из реального индекса вместо восьми жёстко заданных названий. Три подсказки на телефоне, шесть на компьютере.
- Сделать карточки магазинов аккуратнее и плотнее без отказа от ярких акцентов, оставить 6 мобильных / 12 прочих карточек.
- Не менять порядок блоков и механизмы переходов. Главные купоны остаются выше спонсорских тизеров.

## Критерий результата
- В 390×844 пользователь видит поиск и первую строку реальных магазинов уже на первом экране.
- В 1440×900 сохраняется фирменный характер и уменьшена высота Hero.
- Не возникает горизонтального скролла на 360/390/768/1440.
- Поиск, сценарий FARFOR, купоны, ERID, SEO и ограничения даты сохраняются; все проверки GitHub Actions проходят.
- Сравнение одинаковых разрешений в GitHub artifact, без Vercel Preview.

## Безопасность
- PR #82 Editorial 3.0 оставить отдельным не слитым черновиком.
- Новый PR также только draft; **никаких merge, Vercel Preview/production, Supabase-мутаций** до согласования.
- Исходные скриншоты `ui-seo-1-1` относятся к сборке `main`, не к последней production-версии и не должны называться её проверенным снимком.

Мобильный первый экран: описательная фраза остаётся на десктопе, но на узких экранах скрыта как дублирующая заголовок/подзаголовок; мобильный ряд быстрых магазинов ограничен двумя названиями. Это делается ради того, чтобы реальные товары/магазины начинались выше по странице.
