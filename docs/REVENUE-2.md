# REVENUE-2 — закрытая финансовая панель ПромоФакта

## Возможности
- /admin/revenue: приватная страница без финансовых JSON API и хранения сырых действий в Supabase/файлах.
- Вход в /admin (STATS_PASSWORD) обязателен; дополнительно нужен отдельный REVENUE_DASHBOARD_PASSWORD.
- Короткая HMAC-подписанная серверная сессия (12 часов) в httpOnly/Secure/SameSite=Strict cookie, путь /admin/revenue.
- REVENUE_SESSION_SECRET — не меньше 32 символов. Если любой секрет отсутствует, доступ закрыт.
- Отчёт Admitad за 7/30/90 дней: подтверждённые, ожидающие, задержанные и отклонённые комиссии в каждой валюте отдельно.
- Динамика комиссий по дням (7/30) или неделям (90); таблица партнёрских программ.
- Подсчёт действий с SubID3=promofact и без маркера; никакого преобразования кликов Метрики в продажи.
- Perfluence без верифицированных статусов заказов не входит в финансовые результаты.

## Безопасность
- Все финансовые запросы только после двух проверок доступа, на сервере.
- OAuth statistics scope, website=ADMITAD_WEBSITE_ID, no-store, лимит 5000 действий, fail-closed.
- Нет публичного JSON endpoint, токенов/номер заказа/SubID4/промокодов в HTML.
- Страница force-dynamic, robots=noindex; даты действий по API, без догадок о часовом поясе.
- Approved — ещё не означает выплату денег; валюты не смешиваются.
- Для роста нагрузки нужен отдельный распределённый rate-limit на вход.

## Перед эксплуатацией
В Vercel Project → Environment Variables → Production добавить серверные:
- STATS_PASSWORD: существующий пароль /admin.
- REVENUE_DASHBOARD_PASSWORD: отдельный сильный пароль, минимум 16 символов.
- REVENUE_SESSION_SECRET: случайный секрет минимум 32 символа, не равный паролю.
- ADMITAD_CLIENT_ID, ADMITAD_CLIENT_SECRET, ADMITAD_WEBSITE_ID с scope statistics.

Vercel connector в текущей сессии вернул 403 при чтении метаданных env: наличие необходимых переменных **не подтверждено**. При их отсутствии панель остаётся заблокированной. Не передавайте секреты через чат, коммиты или публичные логи.

После настройки: /admin → «Доходы» → дополнительный пароль. Проверить переадресацию неавторизованного посетителя и авторизованный агрегированный отчёт без персональных данных.

## Ограничения
- Долговременной истории изменения статусов нет: данные запрашиваются в текущем состоянии, а комиссии позже могут изменяться.
- Максимум 5000 действий за период; при превышении ошибка, а не неполная сумма.
- SubID не всегда присутствует; неатрибутированные действия не приписываем отдельному клику.
- Суммы выплат ещё не сверены с кошельком Admitad.
