# Поиск и выбор предложений — 21 ноября 2026

## Изменения

- Поиск на главной открывает выделенный стрелками результат по Enter. Выбранная подсказка остаётся видимой; промокоды ведут к своей карточке.
- Каталог позволяет изменить запрос на месте, понимает псевдонимы брендов и ошибочную раскладку, сохраняет запрос в адресе. Сброс очищает запрос и фильтры, включая сохранённый город.
- Общий поиск отличает ошибку загрузки от отсутствия предложений, предлагает повторить запрос или открыть каталог. Фокус клавиатуры остаётся внутри окна.
- «Уже покупал» включает явно универсальные предложения и предложения для повторных заказов. Неизвестные условия остаются отдельной группой.
- Региональные ограничения видны наверху карточки. Сохраняются действующие партнёрские ссылки, рекламные отметки, голосование и переход с копированием одним нажатием.
- Добавлено событие `coupon_view`: минимум половина карточки непрерывно видима секунду в активной вкладке. Событие не содержит промокода, поисковой строки и данных покупателя.

## Проверка результата

Повторяемые проверки: `npm run test:shopping-ux`, `npm test`, `npm run lint`, production build и браузерные сценарии CI. Дополнительный браузерный сценарий покрывает узкую шапку, выбор подсказки, ошибочную раскладку, длинный запрос, сброс, ошибку сети и переход к конкретному тестовому предложению.

Событие просмотра означает видимость карточки. Оно не подтверждает применение кода или заказ. Для отчёта воронки требуется проверить цель `coupon_view` в существующем счётчике Метрики и сравнивать результаты с полными отчётами партнёрских кабинетов за одинаковые периоды.
