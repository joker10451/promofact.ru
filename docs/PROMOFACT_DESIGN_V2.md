# ПромоФакт Editorial 3.0 — главная страница

**Статус:** реализация в черновике PR #82, production не изменён. База — утверждённый пользователем Editorial-концепт; не другая цветовая версия PromoFact 2.0.

## Принципы

- Настоящие предложения выше спонсорских тизеров; никаких фиктивных скидок и выдуманных «проверено сегодня».
- Один визуальный язык: тёплый `#f8f6f2`, белые карточки, глубокий сине-графитовый `#172338`, коралловый `#ed3d58`, зелёный только для подтверждённых фактов.
- Крупная редакционная Georgia в главных заголовках и значениях выгоды, Golos Text в интерфейсе; никакие платные шрифты или скачанные ассеты не требуются.
- Шапка и каталог без огромных фоновых баннеров; на десктопе справа от Hero — полезный сценарий «найти → сравнить → получить», а не декоративная сумка с выдуманной скидкой.
- Мобильная версия показывает поиск и реальные магазины без плавающей иллюстрации; у каталога явные фильтры, доступная клавиатурой категория, возможность сброса фильтра и реальная сортировка.

## Уже реализовано

1. Editorial Hero: SEO-смысл «Актуальные промокоды и купоны на скидку», заголовок «Скидки, которые легко найти», действующая подсказка поиска, реальные магазины, реальные счётчики, правый текстовый редакционный блок.
2. Сетка до 12 живых магазинов с актуальными количествами предложений, первые шесть видны на мобильном. Пустые магазины не отображаются как активные.
3. «Предложения с ближайшим сроком»: реальные даты, один купон на магазин, мобильный scroll-snap, сохранение копирования и маркировки `ordText`.
4. Каталог с подписанной категорией `<select>` на всех экранах, фильтрами, поиском, сортировкой и прежними CouponTicket/атрибуцией; карточки имеют цельный editorial-стиль только под `.pf-v3`.
5. Юридическая маркировка, ERID, истинные условия, пути `/store/[slug]`, `/akcii/...`, canonical, sitemap и noindex пустых магазинов не изменены.
6. Вторая часть главной — FAQ, статьи, подборки и обучающие материалы — сохранена ниже живых купонов.
7. CI: Unit, Next Build, SEO, Lint, Playwright 360/390/768/1440; screenshots are GitHub artifact, **no Vercel Preview**.

## Что тестировать визуально

- 360px: заголовок без обрезки, виден рабочий поиск и начало сетки магазинов, нет горизонтального скролла.
- 390px: автодополнение на кириллице, первая группа карточек, размеры кнопок не меньше 42px, доступность категории.
- 768px: карточки не становятся тесными, быстрые фильтры переходят на новую строку, контакты и реклама не теряют читаемость.
- 1440px: редакционный блок рядом с Hero, предложения выглядят целостными, нет неуместных повторных больших баннеров.
- Купон по коду: скопировать/перейти, ошибки буфера и условия; акция без кода: отдельная понятная кнопка.
- Не считать положительный Playwright-тест заменой ручного просмотра скриншотов.
