# ПромоФакт 2.0 — дизайн главной, этап 1

Состояние: визуальная реализация в отдельной ветке, **не опубликована**. Утверждённое направление — чистая светлая витрина, акцент на реальных скидках, поиск и магазины в первом экране.

## Внесено

- Один унифицированный визуальный язык: нейтральный фон, белые карточки, тонкие границы, тёмный текст и один коралловый акцент. Токены `.pf-v2` **не влияют на страницы магазинов, рекламу и внутренние маршруты**.
- Первый экран: крупный читабельный заголовок «Хорошие скидки. Без лишних поисков.», рабочий исходный поиск, подсказки из **реального каталога**, нет выдуманных процентов и сроков, миниатюрная CSS-иллюстрация только на десктопе.
- Шапка: новое начертание логотипа, чёткая навигация и CTA в каталог без потери динамического `MegaMenu` и мобильного меню.
- Популярные магазины: компактные карточки с сохранением реальных ссылок и числа действующих предложений, без пустых неактивных брендов.
- «Скоро заканчиваются»: отдельный блок реальных купонов, сохраняющий сроки, коды, рекламу и партнёрскую атрибуцию (скрытых иллюстративных скидок нет).
- Основной каталог выше рекламных тизеров. Сохранены фильтры, сортировка, группировка, копирование, атрибуция переходов. Удалена **дублирующая** полоса быстрых фильтров.
- Калькулятор, обучение и преимущества остаются доступны в раскрываемом разделе ниже основного каталога, FAQ/статьи не удалены.
- Мобильный экран: шесть реальных магазинов, один столбец карточек, без декоративной иллюстрации. Скриншоты из локального Playwright в GitHub Actions, а не с production.

## Важные ограничения

- Никаких изменений партнёрских URL, ссылок Admitad/Perfluence, ERID, оригинальных изображений Сбера, сроков акций, условий купонов, Supabase или баз данных.
- Макетная иллюстрация с придуманными цифрами скидок **не переносится** в код.
- Не создавать Preview на Vercel. `vercel.json` остаётся с `git.deploymentEnabled["*"] = false`.
- Этап 1 касается только главной: редизайн магазина, категорий и остальных страниц должен быть отдельно утверждён, после оценки скриншотов.
- Выпускать только после зелёных Unit, Build, E2E (360/390/768/1440), SEO, Lint и ручного просмотра скриншотов.

## Критерий готовности

1. На 360/390/768/1440 пикселей работает поиск и виден каталог без горизонтального скролла.
2. Нет дублирования рекламных акций на главной, ERID и юридические данные читабельны.
3. Все скидки берутся только из реальных активных предложений, пустые магазины не рекламируются.
4. Production остаётся прежним до отдельного решения о релизе и восстановления бесплатной квоты Vercel.
