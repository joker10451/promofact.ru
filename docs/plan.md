## Что НЕ трогать (работает)
- Архитектура Next.js + Perfluence + IndexNow
- ISR 10 мин, cron-задачи (healthcheck 09:00, напоминание 1-го числа)

## Риски
- Магазины "скачут" при истечении кодов -> решается дисциплиной ежемесячного обновления
- Яндекс может медленно индексировать (новый сайт) -> даём 2-4 недели

## Механика кодов (важно)
Промокоды Perfluence активны и проходят проверку ТОЛЬКО после:
1. Поста в ТГ по магазину
2. Отправки на проверку в Perfluence
Коды живут ~месяц, потом истекают -> магазин исчезает со страниц (getStores фильтрует по isActive).
После проверки новые коды появляются сами за ~10 мин (ISR=600с). Если нет -> redeploy.
Страницы магазинов без кодов дать нельзя — Perfluence не отдаёт магазин без купонов.
Статьи /sovety — стабильный фундамент (не истекают), поэтому их важно наращивать.
